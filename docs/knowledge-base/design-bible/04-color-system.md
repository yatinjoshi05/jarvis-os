# 04 — Color System

## Purpose

This document establishes the color rules, themes, states, and constraints for Jarvis OS.

## Scope

Defines core background, foreground, border, indicator, and semantic states colors.

## Design Goals

- **OLED Pure Black**: Backgrounds should remain pure black (#000000) for premium aesthetics and power efficiency.
- **Voltage Accents**: Leverage Voltage Yellow (#FAF410) as the primary highlight and action indicator.
- **Muted Underlays**: Secondary panels and borders must utilize muted grays, low-opacity yellows, and dark glass filters.
