# 02 — Design Principles

## Purpose

This document establishes the tactical principles that developers and designers must follow when creating components, screens, or interactions for Jarvis OS.

## Scope

Applicable to all frontend development, desktop wrappers, layouts, responsive scaling, and notifications.

## Design Goals

- **Consistency**: Elements with the same visual weight must have identical sizes and radius tokens.
- **High Contrast Utility**: Ensure primary indicators stand out immediately on the deep black background.
- **Micro-Feedback**: Provide subtle tactile/visual feedback for hover and select actions to make the dashboard feel tactile.
