# 14 — Accessibility

## Purpose

This document defines accessibility guidelines, including contrast ratios, keyboard navigation, and screen reader compatibility.

## Scope

Applicable to all visual outputs, colors, interactive buttons, inputs, and semantic page flows.

## Design Goals

- **High Contrast Compliance**: Muted states must remain readable. Actionable elements must pass contrast checks on black backgrounds.
- **Tab Focus Clarity**: Focus rings must use the primary Voltage Yellow color for clear visual selection.
