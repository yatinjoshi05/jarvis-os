# 09 — Motion Principles

## Purpose

This document establishes motion rules, easing curves, and timing guidelines to ensure smooth animations.

## Scope

Includes transitions, state transformations, globe animations, panel expansions, and notifications.

## Design Goals

- **Purposeful Motion**: Avoid animation for the sake of decoration; use motion to direct focus and clarify layout changes.
- **Organic Snappiness**: Easing curves should feel natural yet swift (e.g., cubic-bezier curves).
