# 13 — Desktop Behavior

## Purpose

This document defines visual details for the desktop application, including window borders, dragging, and notifications.

## Scope

Directly concerns the Electron desktop wrapper package and its integration with the React app.

## Design Goals

- **Frameless Integration**: Use custom high-fidelity window title bars and borders matching the internal tech style.
- **Fluid Dragging**: Implement dragging boundaries that avoid lag or visual tearing.
