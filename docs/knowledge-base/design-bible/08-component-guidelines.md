# 08 — Component Guidelines

## Purpose

This document provides development instructions for building modular, reusable, and self-contained components.

## Scope

Applied to buttons, cards, status badges, forms, terminal blocks, and dialog boxes.

## Design Goals

- **Strict Separation of Concerns**: Each component must manage its own display states and avoid global side effects.
- **Visual hierarchy**: Use borders and Voltage Yellow status lights to guide user actions.
