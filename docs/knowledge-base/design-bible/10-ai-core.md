# 10 — AI Core

## Purpose

This document defines visual states, assets, and specs for the main AI Globe and cognitive feedback indicators.

## Scope

Directly concerns the AI Globe component, loading indicators, and context highlights in terminal responses.

## Design Goals

- **Interactive Presence**: The AI Globe should communicate its focus (Idle, Listening, Processing, Speaking, Executing) through color, speed, and particle density.
- **Glanceable Status**: Make sure the AI's internal state is immediately clear.
