# 12 — Voice UI

## Purpose

This document defines visual cues, waveforms, microphone indicators, and dialog animations during voice communication.

## Scope

Applied to the microphone button, audio waves, dialog bubbles, and overlay cards.

## Design Goals

- **Real-Time Responsiveness**: Ensure that voice visualizations synchronize immediately with user audio signals.
- **Ambient Feedback**: Provide non-intrusive status rings to show when the AI is listening or speaking.
