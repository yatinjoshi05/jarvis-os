# 11 — Dashboard Rules

## Purpose

This document governs the layout grid, hierarchy, visual spacing, and widget styling rules inside the main Dashboard workspaces.

## Scope

Includes cards, mission widgets, activity logs, data modules, and system diagnostic interfaces.

## Design Goals

- **Structured Hierarchy**: Primary logs and visual status cards must occupy grid spaces that prioritize readability.
- **Glassmorphic Depth**: Maintain standard borders and dark transparent panels to give structural depth.
