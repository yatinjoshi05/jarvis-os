# 06 — Spacing & Grid

## Purpose

This document specifies the spacing intervals and layout grids that align objects across the OS window.

## Scope

Defines layout columns, gutters, margins, and card padding.

## Design Goals

- **8px Core System**: Use an 8px base spacing grid for consistent heights, paddings, and alignment.
- **Visual Breathing Room**: Allow ample padding around the AI Globe and dashboard logs to keep the UI clean.
